# Nails n Lash Studio — Website

Sample website for Nails n Lash Studio (Kandivali West, Mumbai) built by Zivora Studios.

## Structure

- `index.html` — page markup (hero, services, booking, location, contact)
- `css/styles.css` — all styling
- `js/app.js` — service filter + booking builder (copies booking details, opens Instagram DM)
- `assets/` — images used on the page (illustrative, not the studio's own work)

## Notes

- 13 services, booking via Instagram DM to @nails_n_lash_studio, ₹200 deposit policy, 9am–10pm appointment-only
- No prices on the page — price on enquiry
- No phone numbers on this version (they go back in later)
